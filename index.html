A filter slides across the image

A filter is a 3 × 3 grid of numbers called weights. Lay it over nine pixels, multiply each pair, and add the nine results. That single number goes into a new image called a feature map. Then move one pixel along and repeat.

Negative results are shown as dark. In a real network the weights are not typed in by anyone. They are learned in step 4.

Input64 × 64 × 3

Gold boxes show how much of the image one pixel sees: 3 pixels across in layer 1, 8 in layer 2 and 18 in layer 3. Click a map to highlight its layer.

Layers build on layers

Each layer runs many filters, like the one in step 2, over the maps from the layer before. Every filter is a 3 × 3 grid of weights.

Between layers the maps are shrunk (pooling). Each 2 × 2 block becomes one number, its largest value, so 64 × 64 becomes 32 × 32 and then 16 × 16. The filter stays 3 × 3, so on a smaller map the same window covers more of the image. The gold box on each map shows this.

These filters were set by hand to show the idea. A real network has dozens to hundreds of filters per layer.

That leaves one question. Where do the weights in each filter come from? In a new network they are random numbers, so its first answers are guesses. Step 4 shows how training finds weights that work.

Training finds the weights

A new network starts with random weights, so its first answers are guesses. Training is how it finds better ones, and it works as a loop.

This is a real, very small network running in your browser. It is shown small squares cut from the two images, each labelled steatotic or not.

  1. Show a labelled square.
  2. Predict.
  3. Compare with the answer. The size of the mistake is the loss.
  4. Nudge every weight slightly to reduce it, then repeat. Backpropagation works out which way to nudge each weight, and gradient descent makes the nudge.

Gradient descent and backpropagation, the maths behind step 4 of the loop, can be hard concepts to grasp and are covered only briefly here. For a clear visual explanation, watch 3Blue1Brown's lesson Gradient descent, how neural networks learn.

Weights fixed. One number per class, from 0 to 1. The highest is the answer.

The trained model answers

Training is over and the weights are now fixed. The same arithmetic runs on a picture the network has never seen.

Move the slider to blend the two images and watch the two numbers change. The network looks at many small squares across the image and averages its answers.

The slider mixes two pictures. It is not a measure of real steatosis. This network has two classes. A model can have as many as the task needs, such as none, mild, moderate and severe, and it reports the one with the highest number.
